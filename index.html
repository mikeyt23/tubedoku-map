Mobile Bookmarklet Generator

Because mobile browsers do not allow web apps to directly access another website's storage, this lightweight bookmarklet extracts your archivedAnswers and completedPuzzles on tubedoku.com and securely bounces back here via a base64 encoded URL parameter.

How to Install on Your Phone (Takes 30 Seconds)

1

Bookmark this page

In Safari, tap the Share button (box with arrow up) → tap Add Bookmark. Name it Export Tubedoku and tap Save.

2

Edit the bookmark with the copied code

Tap the Bookmarks icon (open book) → tap Edit in the bottom right → tap Export Tubedoku → clear the URL and Paste the bookmarklet code → tap Done.

3

Run on tubedoku.com

Go to tubedoku.com where you play. Tap your Safari address bar, type Export Tubedoku, and tap the bookmark suggestion. It will extract your history and redirect straight back here with your stats!

1

Bookmark this page

2

Edit the bookmark URL

Tap Edit at the bottom of the screen (or go to Menu → Bookmarks → tap 3 dots next to the bookmark → Edit). Change the name to Export Tubedoku and paste the bookmarklet script into the URL field.

3

Run on tubedoku.com

Open tubedoku.com. In Chrome's URL bar, type Export Tubedoku and tap the bookmark result to export your game records back to this app.
